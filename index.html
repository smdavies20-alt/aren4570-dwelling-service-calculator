SIZING BASIS

Read before using

  • Phase and neutral selections use copper THW ampacities in the 75°C column under the calculator’s baseline assumptions.
  • The grounding conductor follows the course Table 7.6 mapping supplied for this assignment.
  • Neutral demand is a simplified estimate from the requested line-to-neutral rules. It is not a phase-balance study.
  • Confirm installation conditions, terminal ratings, code provisions, and local requirements independently.
